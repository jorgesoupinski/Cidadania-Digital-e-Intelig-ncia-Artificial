# Portal de Conscientização: Cidadania Digital e Inteligência Artificial

## 🎯 Objetivo do Projeto
Este site foi desenvolvido como parte do Plano de Recuperação Disciplinar da disciplina de **Educação Digital e Computação: Programação e IA**. O objetivo principal é conscientizar a comunidade escolar sobre o impacto das *deepfakes* e a disseminação de desinformação automatizada na sociedade moderna, oferecendo dicas práticas e um quiz interativo para identificação de mídias manipuladas.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização moderna, uso de Flexbox para alinhamento e Media Queries para total responsividade em dispositivos móveis.
* **JavaScript (Vanilla):** Lógica interativa para o quiz de detecção de desinformação e implementação do botão de acessibilidade (Modo Escuro).

---

## 🤖 Uso de Inteligência Artificial e Ética Digital
Em conformidade com as diretrizes de ética digital e os critérios de avaliação (Subcategoria D), este projeto priorizou a produção de conteúdo autoral. A Inteligência Artificial foi utilizada estritamente como co-piloto de estudos para estruturação do código e revisão de bugs.

### Prompts Utilizados para Assistência:
1. *"Como estruturar um validador de quiz dinâmico usando JavaScript Vanilla sem usar bibliotecas externas?"*
2. *"Me dê exemplos de regras de CSS Media Queries para fazer um layout Flexbox que está em linha no desktop ficar em coluna no celular."*

## 🚀 Como Executar o Projeto

2. Abra o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.
